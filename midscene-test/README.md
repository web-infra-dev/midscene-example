# Midscene Test Examples

Examples built with the Midscene Test framework. Each subdirectory is an independent, runnable example.

[Official documentation](https://midscenejs.com/midscene-test/use)

| Example | What you'll learn | YAML cases |
| --- | --- | --- |
| [Parallel cross-platform tests](./parallel-cross-platform-tests/) | Reuse the same YAML cases across concurrent Web, Android and iOS Projects. | [todo.yaml](./parallel-cross-platform-tests/cases/todo.yaml) |
| [Run large suites in parallel](./run-large-suites-in-parallel/) | Generate case files, distribute them across targets and run them concurrently. | [todo.yaml](./run-large-suites-in-parallel/cases/todo.yaml) |
| [Collaborate between platforms](./collaborate-between-platforms/) | Coordinate mobile and Web Agents within one case: phone creates, Web completes, phone verifies. | [handoff.yaml](./collaborate-between-platforms/cases/handoff.yaml) |
